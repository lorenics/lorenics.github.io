## トップを「トップ案B」に差し替え（2026-10-11・未公開）
- LMIグループのトップの動き方（大きな一文・下へ送ると出てくる・角の丸い色面・重なるカード）を参考に、色と工場の線画はロアニクスのものにした。まねしないもの：クリーム色の背景、黒い色面、回転する丸い文字、英語の大見出し
- 見出しは「大手メーカーの設備開発で17年磨いた知見を、すべての企業へ」。社名は見出しに入れず、すぐ下の経歴の帯に「代表はパナソニックの生産設備開発部門に17年従事」と書く（提携・お墨付きと誤解されないため）。見出しを差し替えるときは index.html の h1 の中の2か所（パソコン用 .pc-only とスマホ用 .sp-only）
- 並び：最初の画面 → ロアニクスがやること（暗黙知→形式知→定着）→ お悩み（数字の帯つき）→ 問いかけ（赤ペンの線＋無料診断ボタン）→ サービス（遡る・渡す・回すのカードが重なる）→ 導入事例 → 選ばれる理由 → 無料診断 → よくある質問
- 動きはCSSのスクロール連動（animation-timeline）だけ。対応していないブラウザでは動かずに最後の形で表示される。場面を画面に止める動きは使わない（空白が出るため）
- 動く文字にグラデーションの切り抜きは使わない（Safariで文字が消えることがある）。青い文字は単色 #0a5fd0
- OSで動きを減らす設定の人にも同じ動きを見せ、その人にだけ左下に「アニメーションを停止する」ボタンを出す（js/top.js）
- 「遡る」のカードは「例：ラダー（PLCのプログラム）なら」と書き、PLC専門に見えないようにしている
- 赤ペンの線は images/v3/redpen-line.svg（PNGから作り直したもの）
- デザインの元は Claude Design のキャンバス「ロアニクス トップページ」のトップ案B（パソコン・スマホ）
- 「つくるものの例」（2026-10-11 追加）：「ロアニクスがやること」のすぐ下に、PLC教育でつくった実際の画面（会員サイト・3Dシミュレータ）を「例」として載せた。画像は images/v3/ex-member.webp・ex-sim.webp（スマホ用の切り抜きは -sp.webp）。会員サイトの画面は、下に出ていたURLの部分を切り落としてある
- 会員サイトの例の見出しは「自社独自の教育コンテンツで、教育を内製化する」。すぐ下に3つのバッジ「教育工学 × 技能五輪 × パナソニック17年」。バッジは縦に並べて×を左の列に置く（横に並べると行の端に×だけが残り、消すボタンのように見えるため）
- 「製造業教育系No.1 YouTuber」のバッジと、その根拠を書く注記は外した（2026-10-11、本人の判断）。「No.1」を戻すときは、何で1位か・いつの時点か・誰が調べたかを必ず添える
- シミュレータの例の見出しは「技術者に必要なのは、体験できる環境」。ラダーの説明にはしない
- 数字の帯（2026-10-12 直した）：91.1%は「重視している」51.8%＋「やや重視している」39.3%、33.3%は「うまくいっている」1.9%＋「ややうまくいっている」31.4%。ラベルに（やや重視を含む）（ややうまくいっているを含む）を付け、上の一文も「それでも、うまくいっている（ややを含む）のは3社に1社です」にした。かぎかっこで「うまくいっている」とだけ書くと、それだけで33.3%に読めるため

- 背景に漂う絵（2026-10-12・top-cases・未公開）：js/drift.js がキャンバス1枚を画面のいちばんうしろ（z-index:-1）に描く。ロゴのしずくを魚の群れのように、らせん（遺伝子）と回路の線をうっすら漂わせる（本人の指示：存在感は出さず、魚が泳いでいるイメージ。素材のストック画像はそのまま使わない）。各段の背景（最初の画面・やること・つくるものの例・お悩み・問いかけ・選ばれる理由）は、白の上で今と同じ色になる透ける色に置き換えて、うしろの絵が見えるようにした。「アニメーションを停止する」を押すと止まる
